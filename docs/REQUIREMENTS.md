# Free Quranic Learning Portal
## Software Requirements & Project Overview

**Mission:** Provide free Quranic education worldwide in English, Urdu, and Arabic for children, adults, and new Muslims.

## User Roles

1. **Super Admin** - Manage users, courses, schedules, and platform activity.
2. **Teacher** - Conduct classes, assign homework, track progress.
3. **Student** - Attend classes, access resources, complete assignments.
4. **Parent** - Monitor attendance, progress, and communicate with teachers.

## Core Courses

* Nazra Quran
* Tajweed
* Hifz-ul-Quran
* Tafseer
* Salah (Prayer Practice)
* Islamic Studies

## Key Features

* **Multi-language support:** English, Urdu, Arabic
* **Live video classes:** One-to-one and group
* **Teacher availability scheduling**
* **Attendance tracking**
* **Homework and assignment management**
* **Progress tracking:** Nazra, Hifz, Tajweed, and Tafseer
* **Notifications and reminders**
* **Parent dashboard**
* **Resource library:** PDFs, videos, audio lessons

## Additional Features

* **Community discussion forum**
* **Digital certificates**
* **Class recordings**
* **Learning pathways:** Beginner, Intermediate, Advanced
* **Volunteer teacher program**
* **Teacher verification and badges**

## Accessibility

* **Mobile-friendly design**
* **Low bandwidth mode**
* **Dark mode**
* **Audio-only classes**
* **Subtitle support**
